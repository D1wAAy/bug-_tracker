# Мини-трекер ошибок EKEB
Консольная программа на Python: журнал ошибок сайта колледжа. Данные — список словарей в памяти, без файлов и библиотек.

## Запуск
python bug_tracker.py

## Возможности
- find_bug — поиск записи по id
- filter_bugs — отбор по статусу и серьёзности
- add_bug — добавление (ID = максимальный + 1, статус open)
- change_status — смена статуса по разрешённым переходам
- build_report — отчёт по статусам, серьёзности и нерешённым high
- start_selected — массовый перевод open → in_progress (все или ни одной)

Переходы: open → in_progress, in_progress → open/closed, closed → open.

Функции не используют input() и print(); весь ввод и вывод в меню. Меню (пункты 1–7, выход 0) повторяется до 0; неверный ввод даёт сообщение и не меняет данные.
